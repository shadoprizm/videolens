# Chrome 線上應用程式商店文案 — 繁體中文

## 名稱

VideoLens — YouTube 影片摘要

## 簡短說明

將 YouTube 影片和本機檔案轉化為您所選語言的專業時間戳記報告。支援隱私自備金鑰模式和選用 Pro。

## 詳細說明

```
VideoLens 可分析您正在觀看的影片，並直接在 Chrome 側邊欄中產生結構清楚、附時間戳記的書面報告。

最新功能 — 版本 0.4.4
• 更清爽的報告版面，增加留白並強化章節區隔
• 長篇執行摘要自動分成易讀段落，原文內容保持不變
• 關鍵發現採用編號，並將附時間戳記的證據分行顯示
• 保留版本 0.4.3 新增的完整拉丁美洲西班牙文、羅馬尼亞文和印地文介面

開啟 YouTube 影片或其他包含 HTML5 播放器的頁面，選擇報告類型，然後告訴 VideoLens 您想瞭解的內容。VideoLens 會取樣影片畫面、讀取可用字幕，並產生以影片證據為依據的分析；每項發現都會標示準確時間點。本機影片檔案同樣適用（mp4 / webm / mov），20 分鐘以內的檔案還可直接轉錄音訊。

多語言支援
• 完整的英文、簡體中文、繁體中文、拉丁美洲西班牙文、羅馬尼亞文和印地文介面
• 報告可使用英文、簡體中文、繁體中文、拉丁美洲西班牙文、巴西葡萄牙文、日文、韓文、法文、德文、羅馬尼亞文或印地文
• 可自動使用瀏覽器語言，或選擇「與影片相同」
• 後續問答和匯出檔案會保持所選報告語言
• VideoLens 會優先選擇與所選語言相符的 YouTube 字幕，不再預設優先英文

報告與專項模式
• 詳細報告、核心洞察、教學指南、訪談 / Podcast
• 錯誤報告、會議紀要、使用者體驗評審、產品展示
• 內容評審、隱私掃描

兩種清楚的使用模式
隱私 / 自備金鑰模式永久免費。分析流程在瀏覽器中執行；所選影片的畫面、音訊或字幕、頁面標題和提示詞會使用您的金鑰直接傳送給 OpenAI，VideoLens 不會接收這些內容。金鑰只保存在您的裝置上。OpenAI 使用費直接由您的 OpenAI 帳戶負擔。

Pro / 代管模式不需要設定 API 金鑰。分析內容會安全地經由 VideoLens 和 Vercel AI Gateway 傳送給目前設定的 AI 供應商（目前為 OpenAI），並計入代管報告額度。免費帳戶包含一份代管體驗報告。Pro 每個日曆月包含 20 份代管報告，價格為每月 12 美元或每年 99 美元。原始畫面和音訊不會被保留。只有在您主動開啟雲端儲存時，完成的報告才會存入雲端資料庫。

其他功能
• 針對已分析時間軸繼續提問，並取得附時間戳記的回答
• 完成的報告和後續問答會自動儲存到本機資料庫，可繼續上次報告、重新開啟或刪除；VideoLens 不限制本機報告數量，也不會同步這些內容
• 下載完全獨立、可離線使用的專業 HTML 報告
• 開啟列印版報告並透過 Chrome 儲存為 PDF
• 匯出 Markdown 或 JSON，或複製為文字
• 開源（MIT）：github.com/shadoprizm/videolens

限制說明
受 DRM 保護的播放器（Netflix、Disney+ 等）無法擷取，這是瀏覽器的安全限制。暫不支援直播。頁面內影片的音訊分析仰賴可用字幕；20 分鐘以內的本機檔案可直接轉錄。部分網站的跨來源安全策略也可能阻止畫面擷取。
```
