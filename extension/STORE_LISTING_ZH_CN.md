# Chrome 应用商店文案 — 简体中文

## 名称

VideoLens — YouTube 视频总结

## 简短说明

将 YouTube 视频和本地文件转化为您所选语言的专业时间戳报告。支持隐私自备密钥模式和可选 Pro。

## 详细说明

```
VideoLens 可分析您正在观看的视频，并直接在 Chrome 侧边栏中生成结构清晰、带时间戳的书面报告。

最新功能 — 版本 0.4.4
• 更清爽的报告版式，增加留白并强化章节区分
• 长篇执行摘要自动分成易读段落，原文内容保持不变
• 关键发现采用编号，并将带时间戳的证据分行显示
• 保留版本 0.4.3 新增的完整拉丁美洲西班牙语、罗马尼亚语和印地语界面

打开 YouTube 视频或其他带 HTML5 播放器的页面，选择报告类型，然后告诉 VideoLens 您想了解的内容。VideoLens 会采样视频画面、读取可用字幕，并生成以视频证据为依据的分析；每项发现都会标注准确时间点。本地视频文件同样适用（mp4 / webm / mov），20 分钟以内的文件还可直接转录音频。

多语言支持
• 完整的英语、简体中文、繁体中文、拉丁美洲西班牙语、罗马尼亚语和印地语界面
• 报告可使用英语、简体中文、繁体中文、拉丁美洲西班牙语、巴西葡萄牙语、日语、韩语、法语、德语、罗马尼亚语或印地语
• 可自动使用浏览器语言，或选择“与视频相同”
• 后续问答和导出文件会保持所选报告语言
• VideoLens 会优先选择与所选语言匹配的 YouTube 字幕，不再默认优先英语

报告与专项模式
• 详细报告、核心洞察、教程指南、访谈 / 播客
• 错误报告、会议纪要、用户体验评审、产品演示
• 内容评审、隐私扫描

两种清晰的使用模式
隐私 / 自备密钥模式永久免费。分析流程在浏览器中运行；所选视频的画面、音频或字幕、页面标题和提示词会使用您的密钥直接发送给 OpenAI，VideoLens 不会接收这些内容。密钥只保存在您的设备上。OpenAI 使用费直接由您的 OpenAI 账户承担。

Pro / 托管模式无需设置 API 密钥。分析内容会安全地经由 VideoLens 和 Vercel AI Gateway 发送给当前配置的 AI 提供商（目前为 OpenAI），并计入托管报告额度。免费账户包含一份托管体验报告。Pro 每个日历月包含 20 份托管报告，价格为每月 12 美元或每年 99 美元。原始画面和音频不会被保留。只有在您主动开启云端保存时，完成的报告才会存入云端资料库。

其他功能
• 针对已分析时间线继续提问，并获得带时间戳的回答
• 完成的报告和后续问答会自动保存到本地资料库，可继续上次报告、重新打开或删除；VideoLens 不限制本地报告数量，也不会同步这些内容
• 下载完全独立、离线可用的专业 HTML 报告
• 打开打印版报告并通过 Chrome 保存为 PDF
• 导出 Markdown 或 JSON，或复制为文本
• 开源（MIT）：github.com/shadoprizm/videolens

限制说明
受 DRM 保护的播放器（Netflix、Disney+ 等）无法采集，这是浏览器的安全限制。暂不支持直播。页面内视频的音频分析依赖可用字幕；20 分钟以内的本地文件可直接转录。部分网站的跨域安全策略也可能阻止画面采集。
```
