# Chrome Web Store सूची — हिन्दी

## नाम

VideoLens — YouTube वीडियो सारांश

## संक्षिप्त विवरण

YouTube वीडियो और स्थानीय फ़ाइलों को समय-चिह्न वाली पेशेवर रिपोर्ट में बदलें। अपनी कुंजी वाला निजी मोड और वैकल्पिक Pro।

## विस्तृत विवरण

```
VideoLens आपके चल रहे वीडियो का विश्लेषण करके Chrome के साइड पैनल में एक
व्यवस्थित, समय-चिह्न वाली रिपोर्ट बनाता है।

नया — संस्करण 0.4.4
• अधिक खाली जगह और स्पष्ट अनुभागों के साथ साफ़ रिपोर्ट लेआउट
• लंबे कार्यकारी सारांश का पाठ बदले बिना पढ़ने योग्य पैराग्राफ़ों में विभाजन
• क्रमांकित मुख्य निष्कर्ष और अलग पंक्तियों में समय-चिह्न वाली जानकारी
• संस्करण 0.4.3 की पूरी हिन्दी इंटरफ़ेस उपलब्ध रहती है

YouTube वीडियो, अन्य HTML5 प्लेयर या स्थानीय फ़ाइलें (mp4 / webm / mov)
विश्लेषित करें। VideoLens फ़्रेम के नमूने और उपलब्ध कैप्शन लेकर हर निष्कर्ष
को वीडियो के सटीक समय से जोड़ता है।

निजी मोड मुफ़्त है और आपकी OpenAI कुंजी इस्तेमाल करता है। कुंजी Chrome में
रहती है और सामग्री सीधे OpenAI को जाती है; VideoLens उसे प्राप्त नहीं करता।
वैकल्पिक Pro प्रबंधित मोड के लिए API कुंजी की आवश्यकता नहीं है।

हर रिपोर्ट और उसके अनुवर्ती सवाल-जवाब निजी स्थानीय लाइब्रेरी में अपने-आप
सहेजे जाते हैं। रिपोर्ट खोजें, दोबारा खोलें, निर्यात, पुनर्स्थापित या मिटाएँ।
HTML डाउनलोड, PDF प्रिंट और Markdown या JSON निर्यात भी उपलब्ध हैं।

DRM-सुरक्षित प्लेयर और लाइव स्ट्रीम समर्थित नहीं हैं। अन्य साइटों पर कैप्चर
ब्राउज़र की क्रॉस-ऑरिजिन सुरक्षा से सीमित हो सकता है।
```
