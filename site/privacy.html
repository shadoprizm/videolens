Privacy Policy

Last updated: August 15, 2026 · Applies to videolens.io, the hosted app, and the VideoLens Chrome extension.

The short version

VideoLens is built so that we don't have your data. Your videos are processed either on your own machine, in your own browser (the extension), or in an ephemeral session (the hosted app). Your OpenAI API key is yours: the extension stores it only on your device, and the hosted app holds it only for the duration of your session. We run no analytics on your video content and we never see your reports.

Chrome extension

  • Analysis requests. The selected video's frames, audio or captions, page title, and your prompt are processed inside the extension and sent to exactly one place: OpenAI's API (api.openai.com), using your own API key, to generate transcripts, frame descriptions, and the analysis. They are never sent to VideoLens servers — we don't have any.
  • Your OpenAI API key. Stored in chrome.storage.local on your device only. It is not synced between browsers and is transmitted only to api.openai.com. Remove it any time in Settings.
  • Analysis results. Reports, timelines, and Q&A history exist only in your browser. Exporting saves files to your device.
  • Browsing data. The extension reads a page only when you invoke it on that page (Chrome's activeTab permission), solely to find the video element, captions, and page title. It does not track your browsing, run in the background, or inject anything into pages you haven't invoked it on.
  • Analytics. The extension contains no analytics, telemetry, or error reporting of any kind.

Chrome Web Store Limited Use. VideoLens's use and transfer of information received through Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. The extension uses this information only to provide the video-analysis features the user requests.

Hosted app (app.videolens.io)

  • Your OpenAI API key is held in session memory only and is never written to a database. Closing the tab discards it.
  • Uploaded videos and generated artifacts live in an ephemeral per-session cache used to make re-runs cheap, and are not retained as a dataset or shared.
  • The hosted app writes privacy-safe product events to its operational logs so we can measure whether the workflow succeeds. These events contain a random session identifier, workflow and mode, upload-versus-URL source type, success or non-sensitive error category, export format, and coarse duration or performance buckets.
  • Hosted-app product events never include videos, filenames, source URLs, prompts, reports, transcript text, extracted images, API keys, email addresses, or persistent cross-session identifiers.

Marketing-site analytics (videolens.io)

  • The public marketing site uses Vercel Web Analytics and Speed Insights to measure aggregate page visits, referrers, device/browser categories, approximate country or region, Core Web Vitals, and clicks on key links such as Launch App and GitHub.
  • Vercel Web Analytics does not use third-party cookies and stores anonymized, aggregated data. Conversion events include only the destination category and public page path — never video content, prompts, reports, API keys, or email addresses.
  • The Chrome extension remains free of analytics and telemetry. The hosted app records only the limited operational product events described above; measurement never includes analyzed content or reports.

Third parties

  • OpenAI — processes the audio chunks and frames you analyze, under your own account and OpenAI's privacy policy.
  • Vercel — hosts videolens.io and provides privacy-friendly aggregate Web Analytics and Speed Insights for the public marketing site.
  • Railway — hosts app.videolens.io and its operational logs, including the limited hosted-app product events described above.
  • There are no ad networks or data brokers, and analytics events never include video content, prompts, reports, or API keys.

Your choices

  • Remove your API key or uninstall the extension at any time — all locally stored data (key and settings) is deleted with it.
  • For any privacy question, email support@videolens.io.

Changes

If this policy changes materially, the "last updated" date above will change and the new version will be posted at this URL. The extension never gains new data collection silently — Chrome requires updated permissions to be re-approved.
